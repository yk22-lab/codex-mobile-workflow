# ベビーチェア選びテスト

暮らしの条件から、ベビーチェア選びで優先したいことを60秒で整理する公開LPです。

## スマホでの作業フロー

1. ChatGPTのCodexでこのリポジトリを選び、目的と完成条件を伝える。
2. Codexが変更・テスト・Pull Requestを作成する。
3. GitHubアプリで差分とChecksを確認する。
4. プレビューURLをスマホで開き、問題なければPRをマージする。

## PCなしで新規プロジェクトを始める手順

### 最初の一回だけ

1. GitHubアプリで、新しい公開リポジトリを作る。名前は内容が分かる英小文字にする。
2. ChatGPTのCodexでGitHubを接続し、そのリポジトリを選べるようにする。
3. Codexの環境設定で、必要ならセットアップコマンドを登録する。Nodeのサイトなら通常は `npm ci`、確認コマンドは `npm run lint` と `npm test`。

### 新しいアイデアを形にするとき

1. ChatGPTのCodexを開き、「新規タスク」を選ぶ。
2. 対象リポジトリを選び、下の依頼文を送る。
3. Codexがクラウド上で実装・テスト・Pull Request作成まで進める。
4. スマホでPRの要約、変更差分、Checks、プレビューURLを確認する。
5. 問題なければGitHubアプリからPRをマージする。

### 新規プロジェクト用の依頼文

> このリポジトリに、新しいWebプロジェクトを作ってください。\
> 目的: （誰の、どんな困りごとを解決するか）\
> 完成条件: （画面・機能・見た目）\
> 技術選定は小さく始められ、スマホ確認しやすい構成にしてください。\
> 秘密情報・個人情報は追加しないでください。\
> 実装後は lint と test を実行し、プレビューを用意してPRを作成してください。\
> PR本文は日本語で、変更概要・テスト結果・スマホで見る項目・プレビューURLを書いてください。

### うまくいかないとき

- ChatGPTアプリにCodexが見当たらなければ、スマホのSafariからCodexを開く。
- ChatGPTの「Remote」は、起動中のPCを遠隔操作するための機能。PCなしの作業には使わない。
- 秘密情報、顧客情報、未公開の案件資料を使う場合は、新規の**非公開**リポジトリに分ける。

## 安全ルール

- APIキー、トークン、パスワード、`.env`、個人情報は置かない。
- 実際の設定値はホスティング先の秘密設定に登録する。
- 詳細は [SECURITY.md](SECURITY.md) と [AGENTS.md](AGENTS.md) を参照する。

## 開発

必要環境: Node.js 22以上

```bash
npm install
npm run dev
npm run lint
npm test
```

`npm test` はビルドと、LPの基本表示を確認します。
