# Codex Mobile Workflow

スマホからAIに仕事を任せ、GitHubで安全に確認・公開するための作業場所です。

## このリポジトリに置いてよいもの

- 公開してよい小規模サイト、LP、デモ、テンプレート
- サンプルデータとダミー画像
- 作業手順、テスト結果、プレビューURL

## 絶対に置かないもの

- APIキー、トークン、パスワード、.env
- 顧客名・メールアドレス・住所などの個人情報
- 未公開の案件資料、見積、アクセス情報
- 権利関係が未確認の画像・文章・動画

## スマホでの作業手順

1. ChatGPT の Codex で、このリポジトリを選んで依頼する。
2. 「変更後はテストし、PRを作成。日本語で要約・テスト結果・確認項目・プレビューURLを書く」と指示する。
3. GitHubアプリで PR の変更内容と Checks を確認する。
4. プレビューをスマホで開き、問題なければPRをマージする。

## 最初に使う依頼文

> 目的: 〜〜
> 完成条件: 〜〜
> 秘密情報を追加・表示・コミットしないでください。
> 変更後はテストを実行し、PRを作成してください。
> PR本文は日本語で、変更概要・テスト結果・スマホで確認する項目・プレビューURLを書いてください。

詳しいAI作業ルールは [AGENTS.md](AGENTS.md)、安全ルールは [SECURITY.md](SECURITY.md) を参照してください。
